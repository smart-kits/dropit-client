# dropit for iOS（快捷指令）

[English](./README.md) · **简体中文**

iPhone 和 iPad 上最主要的投递入口：**分享面板**和**轻点背面**。
分享照片、视频、文件、一条链接或一段文字，会弹出一条通知告诉你发出了什么 —— 比如「已发送 3 张照片/视频」。

![扫码配对、设置一次快捷指令；之后在 Safari 或相册里「分享 → dropit」，或敲两下手机背面发送剪贴板。](../media/ios-tour.webp)

<sub>iPhone 的系统界面是画的，发出和收到的内容是真实的。画面内容：Lonely Planet · NASA 照片（公共领域）。</sub>

## 安装（点一下）

1. 在 iPhone 或 iPad 上用 Safari 打开 **https://dropit.smart-kits.xyz**，点「**安装快捷指令**」，再点「**添加快捷指令**」。
2. 配对：在已经用上 dropit 的设备上生成配对码和二维码（Web 收件箱 →「加一台设备 → 生成配对码」），
   用 iPhone 相机扫码，点「**设置快捷指令**」。快捷指令会打开并提示「配对完成」。

就这样 —— 在任何 App 里分享，选 **dropit**；也可以绑到「轻点背面」（见下文）。
快捷指令会成为一台**只能投递**的独立设备（`ingest_only`）：token 万一泄露，也读不到内容、不能配对设备、不能改设置。
用来配对的那个浏览器不会登录。

安装的文件由 [`build.py`](./build.py) 生成（在 Mac 上运行 `python3 shortcuts/build.py` 会顺带签名）。

- **照片、视频、文件、PDF**：逐个上传，原样送达。一次选好几样，其他设备上看到的是同一次投递。
- **文字、链接、备忘录**：按文字发送。网页里的 PDF 发的是它的链接；想发 PDF 本身，先存到「文件」App 再分享。
- **没有输入**（从主屏幕或轻点背面运行）：投递剪贴板里的内容。从分享面板进来时绝不会改发剪贴板。
- 1 分钟内紧挨着再发一次同样的内容，只算一次（防连点）；隔开再发或过了 1 分钟，照常送达。
- 已经配过对时，再用配对码配一次会先问你是否替换。
- 提示默认英文；手机设为中文时显示中文。

## 自己动手搭

想自己搭的话，步骤如下。可以在 Mac 上搭：快捷指令 App 会通过 iCloud 同步到 iPhone。

## 一 · dropit 配对（只跑一次）

| # | 动作 | 配置 |
|---|---|---|
| 1 | 要求输入 | 文本，提示「配对码」 |
| 2 | 获取 URL 内容 | `{API}/v1/pair/claim` · POST · JSON<br>`{"code": 提供的输入, "device_name":"iPhone", "scope":"ingest_only"}` |
| 3 | 获取词典值 | 键 `token`，取自上一步结果 |
| 4 | 存储文件 | 存到 `iCloud Drive/Shortcuts/dropit-token.txt`，**覆盖已有文件** |
| 5 | 显示通知 | `dropit：配对完成` |

- 配对码在另一台设备上生成 —— 命令行用 `dropit code`，Obsidian 在「设置 → dropit → 配对码」。6 位，5 分钟内有效；大小写、空格、连字符都无所谓，`0`/`O`、`1`/`I`/`l` 打混了也能认。
- 第 1 步也可以换成**扫描二维码**，扫配对二维码，把扫出来的文字原样传给 `code`。
- 用配对码加入时，手机拿到的是**只投**（`ingest_only`）的 token，这是有意的：万一泄露，也读不到你的内容、不能配对新设备、不能改设置。
- 它只负责**加入**已有账号。快捷指令收不到内容、也发不了配对码，在它里面建的账号既看不到任何东西、也加不了别的设备。先在别的客户端上建账号 —— 只有 iPhone？用 Safari 打开网页收件箱建号，再在它的「加一台设备」里设置快捷指令。

## 二 · dropit（投递）

新建快捷指令，在「详细信息」里打开**在共享表单中显示**，接收类型只留 **URL** 和**文本**。

| # | 动作 | 配置 |
|---|---|---|
| 1 | 获取文件 | `iCloud Drive/Shortcuts/dropit-token.txt` —— **关掉**「如果未找到则出错」 |
| 2 | 如果 | 「文件」**没有任何值** → 显示通知 `请先运行「dropit 配对」` → 停止 |
| 3 | 词典 | 三个键，见下表 |
| 4 | 获取 URL 内容 | `{API}/v1/ingest` · POST · JSON（第 3 步的词典）<br>头部 `Authorization` = `Bearer ` + 第 1 步的文件 |
| 5 | 获取词典值 | 键 `seq`，取自「URL 的内容」 |
| 6 | 如果 | 「词典值」**有任何值** → 振动；**否则** → 显示通知 `dropit：投递失败` |

第 3 步的词典：

| 键 | 值 |
|---|---|
| `kind` | `url` 或 `text` |
| `raw` | 快捷指令输入 |
| `source` | `ios-shortcut` |

不需要算哈希，也不需要时间戳 —— 去重和时间都不用你操心。

要判断 `seq`，不能只判断「有任何值」：出错时服务端也会返回内容（`{"error": …}`），
只判断有没有值的话，失败也会振动。投递成功（包括同一天重复投）的返回里才带 `seq`。

### 轻点背面

「设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下」→ 选 `dropit`。

有些 App 不提供分享面板，可以再复制一份从**剪贴板**取内容的版本
（把第 3 步的 `raw` 换成「剪贴板」）：复制，然后敲两下手机背面。

## 你会看到什么

| 现象 | 含义 | 怎么办 |
|---|---|---|
| 轻震 + 通知「已发送 …」 | 投递成功：几个、什么（照片/视频、文件、PDF、文字、链接） | — |
| 通知「刚才已经发过这条」 | 1 分钟内紧挨着发了同样的内容，没有重复发送 | 想再发一次，等 1 分钟 |
| 通知「发送失败：…」/「有的没发出去：…」 | 被拒收了，后面写着原因（超过单条大小上限、空间满了、需要重新配对…） | 按提示处理；需要重新配对的，重新走安装第 2 步 |
| 通知「连不上 dropit，或文件超过 100 MB」 | 没拿到服务的回应：网络断了，或文件太大 | 检查网络；单个文件最大 100 MB |
| 快捷指令弹出错误 | 没网 | 检查网络 |
| 通知「还没配对」 | 还没配对，或者 iCloud 把 token 文件清掉了 | 重新配对（安装第 2 步） |

## 已知限制

- 单个文件最大 100 MB（免费版 5 MB）。长视频很容易超过。
- PDF 和 JSON 文件拿不到原来的文件名，会按发送时间命名（如 `dropit 09-30 15.08.pdf`）。照片和其他文件保留原名。
- 真机验证过的：iOS 26.6.1 上的配对和发文字；iOS 27 上分享照片（单张和多张）、视频、PDF、Excel、JSON。上面「自己动手搭」的步骤只覆盖文字和链接，还没有在真机上完整走过。
- 遇到问题或有建议：[提一个 issue](https://github.com/smart-kits/dropit-client/issues/new?title=%5BiOS%20Shortcut%5D%20)。issue 是公开的，不要贴 token。
