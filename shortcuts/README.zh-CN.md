# dropit for iOS（快捷指令）

[English](./README.md) · **简体中文**

iPhone 和 iPad 上最主要的投递入口：**分享面板**和**轻点背面**。
分享一条链接或一段文字，手机轻轻一震 —— 已经进队列了。

## 安装（点一下）

1. 在 iPhone 或 iPad 上用 Safari 打开 **https://dropit.realeye.top**，点「**安装快捷指令**」，再点「**添加快捷指令**」。
2. 配对：在已经用上 dropit 的设备上生成配对码和二维码（Web 收件箱 →「加一台设备 → 生成配对码」），
   用 iPhone 相机扫码，点「**设置快捷指令**」。快捷指令会打开并提示「配对完成」。

就这样 —— 在任何 App 里分享，选 **dropit**；也可以绑到「轻点背面」（见下文）。
快捷指令会成为一台**只能投递**的独立设备（`ingest_only`）：token 万一泄露，也读不到内容、不能配对设备、不能改设置。
用来配对的那个浏览器不会登录。

安装的文件由 [`build.py`](./build.py) 生成（在 Mac 上运行 `python3 shortcuts/build.py` 会顺带签名）。
没有输入时（从主屏幕或轻点背面运行），它投递剪贴板里的内容。

## 自己动手搭

想自己搭的话，步骤如下。可以在 Mac 上搭：快捷指令 App 会通过 iCloud 同步到 iPhone。

## 一 · dropit 配对（只跑一次）

| # | 动作 | 配置 |
|---|---|---|
| 1 | 从菜单中选取 | 提示「这是你的第一台设备吗？」；两项：`是，创建新账号` / `否，我有配对码` |
| 2 | └ **是** 分支 | |
| 3 | 　获取 URL 内容 | `{API}/v1/accounts` · POST · JSON `{"device_name":"iPhone"}` |
| 4 | └ **否** 分支 | |
| 5 | 　要求输入 | 文本，提示「配对码」 |
| 6 | 　获取 URL 内容 | `{API}/v1/pair/claim` · POST · JSON<br>`{"code": 提供的输入, "device_name":"iPhone", "scope":"ingest_only"}` |
| 7 | 获取词典值 | 键 `token`，取自上一步结果 |
| 8 | 存储文件 | 存到 `iCloud Drive/Shortcuts/dropit-token.txt`，**覆盖已有文件** |
| 9 | 显示通知 | `dropit：配对完成` |

- 配对码在另一台设备上生成 —— 命令行用 `dropit code`，Obsidian 在「设置 → dropit → 配对码」。6 位，5 分钟内有效；大小写、空格、连字符都无所谓，`0`/`O`、`1`/`I`/`l` 打混了也能认。
- 第 5 步也可以换成**扫描二维码**，扫配对二维码，把扫出来的文字原样传给 `code`。
- 用配对码加入时，手机拿到的是**只投**（`ingest_only`）的 token，这是有意的：万一泄露，也读不到你的内容、不能配对新设备、不能改设置。
- 「是」分支创建账号时拿到的是 `full` token —— 第一台设备必须能给其他设备签发配对码。

## 二 · dropit（投递）

新建快捷指令，在「详细信息」里打开**在共享表单中显示**，接收类型只留 **URL** 和**文本**。

| # | 动作 | 配置 |
|---|---|---|
| 1 | 获取文件 | `iCloud Drive/Shortcuts/dropit-token.txt` —— **关掉**「如果未找到则出错」 |
| 2 | 如果 | 「文件」**没有任何值** → 显示通知 `请先运行「dropit 配对」` → 停止 |
| 3 | 词典 | 三个键，见下表 |
| 4 | 获取 URL 内容 | `{API}/v1/ingest` · POST · JSON（第 3 步的词典）<br>头部 `Authorization` = `Bearer ` + 第 1 步的文件 |
| 5 | 获取词典值 | 键 `seq`，取自「URL 的内容」 |
| 6 | 如果 | 「词典值」**有任何值** → 振动；**否则** → 显示通知 `dropit：投递失败` |

第 3 步的词典：

| 键 | 值 |
|---|---|
| `kind` | `url` 或 `text` |
| `raw` | 快捷指令输入 |
| `source` | `ios-shortcut` |

不需要算哈希，也不需要时间戳 —— 去重和时间都不用你操心。

要判断 `seq`，不能只判断「有任何值」：出错时服务端也会返回内容（`{"error": …}`），
只判断有没有值的话，失败也会振动。投递成功（包括同一天重复投）的返回里才带 `seq`。

### 轻点背面

「设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下」→ 选 `dropit`。

有些 App 不提供分享面板，可以再复制一份从**剪贴板**取内容的版本
（把第 3 步的 `raw` 换成「剪贴板」）：复制，然后敲两下手机背面。

## 你会看到什么

| 现象 | 含义 | 怎么办 |
|---|---|---|
| 一次短震 | 投递成功。同一天重复投同样的内容也算成功 | — |
| 通知「投递失败：…」 | 服务端拒收了，后面的代码说明原因（如 `INVALID_TOKEN`、`RATE_LIMITED`） | token 相关的错误就重新配对 |
| 快捷指令弹出错误 | 没网 | 检查网络 |
| 通知「还没配对」 | 还没配对，或者 iCloud 把 token 文件清掉了 | 重新配对（安装第 2 步） |

## 已知限制

- 目前只支持文本和链接，快捷指令还不能投文件和照片 —— 投文件请用[命令行](../cli/README.zh-CN.md)。
- 一键安装的快捷指令和这些步骤都还没有在真机上完整走通验证过。如果和你看到的不一样，欢迎提 issue。
