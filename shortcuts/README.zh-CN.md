# dropit for iOS（快捷指令）

[English](./README.md) · **简体中文**

iPhone 和 iPad 上最主要的投递入口：**分享面板**和**轻点背面**。
分享一条链接或一段文字，手机轻轻一震 —— 已经进队列了。

由两个快捷指令组成，用系统自带的「快捷指令」App 搭建：

| 快捷指令 | 作用 | 从哪里运行 |
|---|---|---|
| **dropit 配对** | 只跑一次：配对这台设备并保存 token | 手动运行 |
| **dropit** | 投递。没有任何选项，也不用确认 | 分享面板 · 轻点背面 · 主屏幕 |

配对单独拆成一个快捷指令是有意的：投递的路上不能出现任何选择题。

> 目前还没有一键安装链接，请先按下面的步骤手动搭建这两个快捷指令。
> 可以在 Mac 上搭：快捷指令 App 会通过 iCloud 同步到 iPhone，有键盘快得多。

步骤里的 **`{API}`** 是 dropit 的服务地址 —— 和你其他客户端用的是同一个。
可以在命令行的配置里找到（`~/.config/dropit/config.json` 里 `endpoints` 的第一项），
或者在 Obsidian 的「设置 → dropit → 服务地址」里看到。

## 一 · dropit 配对（只跑一次）

| # | 动作 | 配置 |
|---|---|---|
| 1 | 从菜单中选取 | 提示「这是你的第一台设备吗？」；两项：`是，创建新账号` / `否，我有配对码` |
| 2 | └ **是** 分支 | |
| 3 | 　获取 URL 内容 | `{API}/v1/accounts` · POST · JSON `{"device_name":"iPhone"}` |
| 4 | └ **否** 分支 | |
| 5 | 　要求输入 | 文本，提示「配对码」 |
| 6 | 　获取 URL 内容 | `{API}/v1/pair/claim` · POST · JSON<br>`{"code": 提供的输入, "device_name":"iPhone", "scope":"ingest_only"}` |
| 7 | 获取词典值 | 键 `token`，取自上一步结果 |
| 8 | 存储文件 | 存到 `iCloud Drive/Shortcuts/dropit.token`，**覆盖已有文件** |
| 9 | 显示通知 | `dropit：配对完成` |

- 配对码在另一台设备上生成 —— 命令行用 `dropit code`，Obsidian 在「设置 → dropit → 配对码」。6 位，5 分钟内有效；大小写、空格、连字符都无所谓，`0`/`O`、`1`/`I`/`l` 打混了也能认。
- 第 5 步也可以换成**扫描二维码**，扫配对二维码，把扫出来的文字原样传给 `code`。
- 用配对码加入时，手机拿到的是**只投**（`ingest_only`）的 token，这是有意的：万一泄露，也读不到你的内容、不能配对新设备、不能改设置。
- 「是」分支创建账号时拿到的是 `full` token —— 第一台设备必须能给其他设备签发配对码。

## 二 · dropit（投递）

新建快捷指令，在「详细信息」里打开**在共享表单中显示**，接收类型只留 **URL** 和**文本**。

| # | 动作 | 配置 |
|---|---|---|
| 1 | 获取文件 | `iCloud Drive/Shortcuts/dropit.token` —— **关掉**「如果未找到则出错」 |
| 2 | 如果 | 「文件」**没有任何值** → 显示通知 `请先运行「dropit 配对」` → 停止 |
| 3 | 获取当前日期 | — |
| 4 | 词典 | 四个键，见下表 |
| 5 | 获取 URL 内容 | `{API}/v1/ingest` · POST · JSON（第 4 步的词典）<br>头部 `Authorization` = `Bearer ` + 第 1 步的文件 |
| 6 | 如果 | 「URL 的内容」**有任何值** → 振动；**否则** → 显示通知 `dropit：投递失败` |

第 4 步的词典：

| 键 | 值 |
|---|---|
| `kind` | `url` 或 `text` |
| `raw` | 快捷指令输入 |
| `client_ts` | 「当前日期」→ 格式化为 **Unix 时间戳**，再 × 1000（毫秒） |
| `source` | `ios-shortcut` |

不需要算哈希，也不需要格式化日期 —— 去重不用你操心。

### 轻点背面

「设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下」→ 选 `dropit`。

有些 App 不提供分享面板，可以再复制一份从**剪贴板**取内容的版本
（把第 4 步的 `raw` 换成「剪贴板」）：复制，然后敲两下手机背面。

## 你会看到什么

| 现象 | 含义 | 怎么办 |
|---|---|---|
| 一次短震 | 投递成功。同一天重复投同样的内容也算成功 | — |
| 通知「投递失败」 | 没网，或者 token 失效了 | 检查网络；一直失败就重新运行「dropit 配对」 |
| 通知「请先运行「dropit 配对」」 | 还没配对，或者 iCloud 把 token 文件清掉了 | 运行「dropit 配对」 |

快捷指令读不到 HTTP 状态码，所以「没网」和「token 失效」在手机上看起来一样。
这是有意的取舍：投递的路上不加任何东西。

## 已知限制

- 目前只支持文本和链接，快捷指令还不能投文件和照片 —— 投文件请用[命令行](../cli/README.zh-CN.md)。
- 这些步骤还没有在真机上完整走通验证过。如果某一步和你看到的不一样，欢迎提 issue。
