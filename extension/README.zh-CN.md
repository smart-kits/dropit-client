# dropit 浏览器扩展

[English](./README.md) · **简体中文**

把正在看的东西投进 dropit —— 页面、选中的字、链接、图片、文件、截图。
支持 Chrome 和 Edge（Manifest V3）。**只投递**：从不读回你的内容。

## 安装

还没上架 Chrome 应用商店，先用「加载已解压」：

1. `git clone https://github.com/smart-kits/dropit-client.git`
2. 打开 `chrome://extensions`（Edge：`edge://extensions`），打开右上角**开发者模式**
3. 点**加载已解压的扩展程序**，选 `extension/` 文件夹

## 第一次用

这个浏览器还没加入账号时，图标上有个红色 **!**。点它，打开就是「用配对码加入」：

- **已经在别的设备上用 dropit** → 在那台设备上生成配对码（比如 `dropit code`），填进来，点「加入」
- **这是第一台设备** → 表单下面的小字链接「创建新账号」

## 投递

| 你这样做 | 投出去的是 |
|---|---|
| 点图标（或 <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd>），按<kbd>回车</kbd> | **这个页面**：地址、标题，以及页面作者写的简介。如果你选中了文字，弹窗打开时已经填好，回车投的就是这段文字。输入框下面那行总会写清楚回车会投什么 |
| 在输入框里输入或粘贴，<kbd>回车</kbd> | 这段文字（只有一个网址时按链接投）。<kbd>Shift</kbd>+<kbd>回车</kbd> 换行 |
| 把截图或复制的文件粘贴进输入框 | 这个文件。多个文件（加上文字）合成一批送达，最多 16 样 |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | 直接投，不打开任何界面：有选中投选中，没有就投这个页面 |
| 右键选中的文字 | 这段文字，换行保留 |
| 右键链接 | 链接地址。指向文件的链接（PDF、ZIP、图片、视频……）还多一项「把链接指向的文件投进 dropit」 |
| 右键图片 | 「把这张图片投进 dropit」投图片文件；「把图片链接投进 dropit」投它的地址 |
| 右键视频、音频 | 页面播放的是真实文件时，「把这个视频投进 dropit」投文件；流媒体播放器（YouTube 之类）没有文件，只给「把这个页面投进 dropit」 |
| 右键页面空白处，或右键工具栏图标 | 这个页面 |

选中的文字、图片和文件会附一条很短的**来源**：所在页面的地址和标题，别的都不带。

快捷键可以在 `chrome://extensions/shortcuts` 修改。同一处有好几项可用时，Chrome 会把它们收进一个「dropit」子菜单。

**结果可信：**

- **成功** —— 弹窗关闭，图标上亮蓝色 ✓，2.5 秒后消失。一分钟内重复投同样的内容也算成功：会被认出来，不会存两份。
- **失败** —— 在弹窗里：红色「退回」标记加原因，你写的内容留在输入框里。从右键或快捷键投：红色 ✗ **加**系统通知。断网时绝不会显示成功。
- **太大** —— 下载前就先判断：超过你套餐单条上限的文件直接拒绝，不会先下载完再说。

断开这个浏览器：弹窗 →「在这个浏览器上退出」。如果在别处把这个浏览器从账号里移除了，扩展下次投递时会发现，告诉你，并回到「加入」。

## 权限

| 权限 | 用来做什么 |
|---|---|
| `contextMenus` | 右键菜单 |
| `activeTab` + `scripting` | 只对你正在操作的标签页、只在你操作的那一刻：读它的标题、简介和选中的文字，取你右键的图片或文件 |
| `storage` | 这个浏览器的 token 和设置 |
| `notifications` | 右键投递失败时说明原因 |
| 可选：一次一个网站 | 见下文 |

**安装时不要任何网站权限** —— 你不操作，扩展读不了任何网站。

图片和文件**由页面自己去取**，和页面平时加载它们的方式一样，所以大多数网站什么都不用多给。
少数网站不让别的页面读它的文件，这时 dropit 会就**这一个网站**问一次（一个只有一个按钮的小窗口），可以在扩展设置里随时收回。
只认自己、谁都不给的网站没有办法 —— dropit 会直说，并建议改用「把图片链接投进 dropit」。

## 隐私

- 每个浏览器配对成**一台独立的设备**。token 存在浏览器的扩展**本地**存储里，不会同步到你别的浏览器 —— 所以每个都能单独吊销。
- 用配对码加入时，扩展拿到的是**只能投递**的 token：就算泄露，也读不到你的任何内容、不能配对新设备、不能改设置。
- token 永远不进网页：页面只负责把文件内容交出来，投递由扩展完成。

## 文件

```
extension/
├── manifest.json     Manifest V3
├── api.js            请求、地址回退、账号信息
├── payload.js        纯逻辑：元信息与大小、菜单、成批、回车投什么、错误文案
├── page.js           在页面里运行的函数：标题和简介、选中的文字、取文件
├── background.js     右键菜单、快捷键、投递、图标角标与通知
├── popup.html/.js    弹窗：首次配置、投递输入框
├── popup.css         样式（申请权限的小窗口共用）
├── grant.html/.js    就一个网站申请权限的小窗口
├── i18n.js           界面文案（英文 / 简体中文）
└── fonts/            标签字体（OFL，许可文件同目录）
```

没有构建步骤 —— 改完文件重新加载扩展即可。测试：在仓库根目录运行 `node test/extension.test.mjs` 和 `node test/i18n.test.mjs`。

## 限制

- 只投递。要接收，用 [Obsidian 插件](https://github.com/smart-kits/dropit-obsidian) 或 `dropit watch`。
- 桌面 Chrome 没有系统分享面板：电脑上的「分享」就是右键、工具栏或快捷键。
- 从桌面把文件拖到弹窗上不行（点别处弹窗就关了）。请粘贴，或用「选文件」。
- 界面跟随浏览器语言：默认英文，浏览器设为中文时显示简体中文。
